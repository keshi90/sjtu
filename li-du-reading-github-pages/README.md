# 李杜联读

解压后可直接双击 `index.html` 预览。网站使用随包提供的数据，浏览时无需联网获取诗文或字体。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库，将解压后的文件上传到仓库根目录，确保在仓库首页能直接看到 `index.html`、`style.css`、`app.js` 和 `data.js`。
2. 打开仓库的 **Settings → Pages**。在 **Build and deployment** 下选 **Deploy from a branch**。
3. 选择包含网页文件的分支，通常为 `main`，目录选 `/ (root)`，然后保存。发布完成后在同一页查看网站地址。

## 数据与字体

数据来自提供的李白、杜甫单人 CSV 和李杜配对 CSV。相似度保留 G 列原值，诗句根据诗作 ID 和篇内诗句 ID 关联。导读结合所选诗句及上下文撰写。

诗句与篇名优先用系统已安装的思源宋体，界面优先用思源黑体。网页设置了本地回退字体。
